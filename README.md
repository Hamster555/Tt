# Trim Controller

Программный стенд контроллера двух трим-плит. Разработка ведётся через чат, исходники хранятся в GitHub, поведение проверяется в Wokwi.

## Файлы
- `sketch.ino` — прошивка симуляции ESP32-S3.
- `diagram.json` — схема Wokwi с четырьмя кнопками.
- `platformio.ini` — конфигурация сборки через PlatformIO.
- `wokwi.toml` — пути к собранной прошивке для Wokwi CLI.
- `.github/workflows/build.yml` — автоматическая компиляция и, при наличии токена, запуск Wokwi в GitHub Actions.

## Автоматические проверки
При каждом push GitHub Actions выполняет `pio run -e esp32-s3-devkitc-1`. Чтобы запускать ещё и Wokwi-симуляцию на GitHub, создай Wokwi CI token в панели Wokwi CI Dashboard и добавь его в GitHub: **Settings → Secrets and variables → Actions → New repository secret**, имя секрета `WOKWI_CLI_TOKEN`, значение — токен Wokwi. Не вставляй токен в исходники или чат.

Wokwi-проект, который мы будем проверять: https://wokwi.com/projects/477699169574740993.

## Рабочий цикл через чат
1. Опиши изменение, которое нужно сделать.
2. Я изучаю текущие файлы и вношу изменения через GitHub.
3. GitHub Actions собирает прошивку; если добавлен секрет Wokwi, он также запускает облачную симуляцию.
4. При необходимости открой Wokwi в браузере для интерактивной проверки и пришли сюда ошибки из Actions/Serial Monitor.

## Ограничения безопасности
Это симуляция, не прошивка для подключения к реальным трим-плитам. GPIO-выходы не заменяют силовой драйвер, независимые аппаратные блокировки, ручной аппаратный обход ESP32, предохранители, защиту от выбросов и испытания стопорного тока. Режим AUTO в текущем каркасе не реализует алгоритм управления лодкой.
