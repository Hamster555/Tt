# Trim Controller

Программный стенд контроллера двух трим-плит. Разработка ведётся через чат, исходники хранятся в GitHub, поведение сначала проверяется в Wokwi.

## Файлы

- `src/main.cpp` — прошивка симуляции ESP32-S3.
- `diagram.json` — схема Wokwi с кнопками, UART-монитором и виртуальной ESP32-S3.
- `platformio.ini` — конфигурация сборки PlatformIO.
- `wokwi.toml` — пути к собранной прошивке для Wokwi CLI.
- `CONTROL_REQUIREMENTS.md` — требования, проверки прототипа и открытые решения.
- `.github/workflows/build.yml` — сборка, проверка схемы и симуляция в CI.

## Автоматические проверки

При push GitHub Actions собирает прошивку через PlatformIO. Если задан GitHub Actions secret `WOKWI_CLI_TOKEN`, workflow также:

1. Устанавливает закреплённую версию Wokwi CLI и проверяет контрольную сумму.
2. Проверяет `diagram.json` на ошибки.
3. Запускает Wokwi и проверяет ожидаемую строку старта.
4. Сохраняет serial log как артефакт запуска.

Чтобы включить симуляцию, создай Wokwi CI token в панели Wokwi CI Dashboard и добавь его в GitHub: **Settings → Secrets and variables → Actions → New repository secret**, имя секрета `WOKWI_CLI_TOKEN`. Не вставляй токен в исходники или чат.

Wokwi-проект: https://wokwi.com/projects/477699169574740993.

## Рабочий цикл

1. Зафиксировать поведение и критерии приёмки в `CONTROL_REQUIREMENTS.md`.
2. Изменить прошивку и/или виртуальную схему.
3. GitHub Actions собирает и проверяет симуляцию.
4. После выбора реального оборудования отдельно провести стендовые испытания аппаратной части.

## Ограничения безопасности

Это симуляция, не прошивка для подключения к реальным трим-плитам. Позиция приводов и телеметрия пока симулируются. GPIO-выходы не заменяют силовой драйвер, независимые аппаратные блокировки, аппаратный ручной обход ESP32, предохранители, защиту от выбросов и испытания стопорного тока. Режим AUTO пока не реализует алгоритм управления лодкой.
