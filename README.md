# Trim Controller

Программный стенд контроллера двух трим-плит для разработки через ChatGPT + GitHub + Wokwi.

## Состав
- `sketch.ino` — прошивка симуляции для ESP32-S3.
- `diagram.json` — виртуальная схема Wokwi.
- `wokwi.toml` — путь к собранной прошивке для Wokwi CLI.
- `platformio.ini` — конфигурация сборки ESP32-S3.
- `.github/workflows/build.yml` — автоматическая компиляция при изменении исходников.

## Важно
Это программный прототип, не безопасный контроллер реального судна. GPIO в симуляции не заменяют аппаратную блокировку направлений, отдельный аппаратный ручной обход ESP32, предохранители и защиту силовой части. Не подключать к реальным приводам.

## Сборка и Wokwi
GitHub Actions будет собирать прошивку на каждый push и pull request. Проект Wokwi: https://wokwi.com/projects/477699169574740993. Синхронизация с онлайн-редактором Wokwi зависит от функций, доступных в аккаунте; GitHub Actions сам по себе не изменяет файлы редактора Wokwi.
